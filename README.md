# Saudi School Finder

منصة ويب ثنائية اللغة لمساعدة أولياء الأمور في السعودية على البحث عن المدارس ومقارنتها والحصول على توصيات ذكية.

## المزايا
- واجهة عربية RTL وإنجليزية LTR
- دليل مدارس مع بيانات نموذجية
- فلاتر حسب المدينة، المنهج، النوع، المرحلة، الرسوم والتقييم
- مقارنة بين المدارس
- مستشار ذكي تجريبي يعتمد على قواعد واضحة
- API للتوصيات
- تصميم متجاوب للجوال والكمبيوتر
- جاهز للنشر على Vercel

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح: http://localhost:3000

## البناء
```bash
npm run build
npm start
```
