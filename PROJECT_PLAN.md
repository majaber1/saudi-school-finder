# Product Roadmap

## MVP
- Bilingual public website
- Search and filters
- School cards and comparison
- Explainable rule-based recommendations
- Responsive design

## Beta
- PostgreSQL/Prisma integration
- Parent accounts and saved schools
- School claim/verification workflow
- Admin moderation
- Review ingestion and summarization
- Map and distance calculation

## V1
- AI agents for discovery, ranking, review analysis, fee monitoring, and admission alerts
- School subscription plans
- Verified offers
- Application document checklist
- Notifications and analytics

## Governance
- Mark official vs user-provided data
- Audit trail for fee changes
- Review moderation and anti-spam
- Saudi PDPL-aligned privacy controls
- Arabic-first accessibility
